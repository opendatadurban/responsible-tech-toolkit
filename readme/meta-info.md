### Analytics&#x20;

* #### What data do we collect?

Gitbook natively collects some analytics which we push through out GA4 (Google Analytics) account. We choose to keep the data that we collect anonymised. We collect the following:

* Page views
* Dwell time
* Internal link clicks
* Search terms
* Direct feedback
* Device type
* Browser type

{% hint style="info" icon="pencil-line" %}
Learn more about what is collected in [this GitBook guide. ](https://gitbook.com/docs/guides/best-practices/documentation-analytics)
{% endhint %}

* #### Why do we collect it?

We do this to better understand how users interact with the toolkit so we can make improvements that are needs-based. This is done in combination with direct feedback we receive via either the "Contact Us" email address or the native GitBook comment function.



* #### What do we not do with the data?&#x20;
* We do not share this data with anyone outside the OCL organisation.
* We do not sell this data.
* We do not use it to add you to the OCL emailer unless you have expressly asked to be added.
* We do not build profiles on you.

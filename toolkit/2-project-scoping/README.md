# (3) Discovery

The discovery phase exists to surface what's actually needed before any design or build work begins. It is where assumptions get tested against reality by talking to the people who'll use the system, understanding the problem they're trying to solve, and mapping the constraints (technical, legal) that will shape what's possible. Done well, discovery prevents the costliest kind of failure: building the wrong thing.&#x20;

> As the old adage goes, "Failing to prepare is preparing to fail" &#x20;
